# 📊 Dataset Architecture & Data Handling — Silkworm Segmentation

This document describes every dataset inside `data/`, their annotation formats, how they are generated, and how to load them via [`src/dataset_multitask.py`](src/dataset_multitask.py).

---

## 📁 1. Folder Layout

Folder names are short and lowercase. Suffixes tell the content: `_bbox` = bounding boxes, `_seg` = segmentation masks, `_augNk` = augmented to N thousand training images.

```text
data/
├── yolo_bbox/        # Raw: images + YOLO bounding boxes + disease class
├── sam3_seg/         # Pseudo-masks generated by SAM 3 from yolo_bbox
├── silkynet_seg/     # Silkynet multi-larvae images + masks (no disease label)
├── mixed_10k/        # Augmented 10k train (SAM3 + Silkynet) + fixed valid/test
├── sam3_aug20k/      # Augmented ~20k train (SAM3 only) + full SAM3 valid/test
└── test/             # 2 unseen images for quick inference checks
```

Lineage: `yolo_bbox` ──SAM 3──▶ `sam3_seg` ──augment──▶ `sam3_aug20k`
(`mixed_10k` additionally draws from `silkynet_seg`.)

---

## 🏷️ 2. Dataset Specifications

Class mapping used everywhere (first column of every label file): **`0` = Grasserie (diseased), `1` = Healthy**.

### 2.1. `yolo_bbox` — raw YOLO dataset
- Splits: train 7,978 / valid 499 / test 498 images (`images/`, `labels/`, plus `data.yaml`).
- Labels: `<class_id> <x_center> <y_center> <width> <height>` (normalized).
- Train holds 3,989 distinct originals, each exported twice by Roboflow (suffix `_jpg.rf.<hash>`). Valid and test have one copy per original; no original appears in two splits.

### 2.2. `sam3_seg` — SAM 3 pseudo-masks
- Same file names and split sizes as `yolo_bbox`. Contains **no images** (images live in `yolo_bbox`).
- `masks/`: binary PNG (`0` background, `255` body) · `boundaries/`: 2 px contour masks · `labels/`: polygon labels.
- Masks are pseudo-labels produced by [`utils/sam3_label_from_yolo.py`](utils/sam3_label_from_yolo.py) and are not manually verified.

### 2.3. `silkynet_seg` — Silkynet multi-larvae images
- Sub-folders `larvaTrain` (30), `output20221127` (69), `larvaTest` (69), `20221127` (raw images + JSON).
- About 14 small larvae per image, 1280×720, **no disease label**.
- ⚠️ Mask PNGs store the foreground as value **75**, not 255. Thresholding with `> 127` makes them empty — use `> 0`.

### 2.4. `mixed_10k` — augmented train, SAM3 + Silkynet
- train 9,940 (`silkworm_aug10k_*.jpg`) · valid 110 · test 169 (100 SAM 3 + 69 Silkynet).
- ⚠️ Known issues (kept for reproducibility of past runs):
  - Silkynet-derived training images have **empty masks** (see 2.3) and a forced `Healthy` label.
  - 31% of train images contain both classes but carry a single label (first line).
  - The 69 Silkynet test images are near-duplicates of the sources used to generate train.

### 2.5. `sam3_aug20k` — augmented train, SAM3 only (recommended)
- train **19,997** (`aug_*.jpg`) · valid **499** · test **498** (full SAM3 valid/test, not augmented).
- Train classes: Grasserie 9,785 / Healthy 10,212. Every image holds exactly one class.
- Generated with:
  ```bash
  python utils/augment_mixed_10k.py --sam3-only --same-class-paste --name-prefix aug \
      --output-dir data/sam3_aug20k/train --goal 20000 --workers 24 --seed 42
  ```
- Each split has `images/`, `masks/` (0/255), `labels/` (YOLO polygons; line 1 = image class). Train also has `aug_previews/`.

## 🔄 3. Loading Data (`src/dataset_multitask.py`)

```python
from src.dataset_multitask import MultitaskSilkwormDataset
from torch.utils.data import DataLoader

ds = MultitaskSilkwormDataset("data/sam3_aug20k", split="train", img_size=256, augment=True)
loader = DataLoader(ds, batch_size=8, shuffle=True, num_workers=4, pin_memory=True)

for images, masks, class_labels in loader:
    # images:       [B, 3, 256, 256] float32 (ImageNet-normalized)
    # masks:        [B, 1, 256, 256] float32 (0.0 / 1.0)
    # class_labels: [B] int64 — 0 = Grasserie, 1 = Healthy, -1 = no label (ignored by the cls loss)
    pass
```

`split` is one of `"train"`, `"valid"`, `"test"`. Flip/rotate augmentation applies to `train` only.

## 🛠️ 4. Utilities (`utils/`)

```bash
# Generate pseudo-masks from YOLO boxes (SAM 3)
python utils/sam3_label_from_yolo.py \
    --input-yaml "data/yolo_bbox/data.yaml" \
    --output-dir "data/sam3_seg" \
    --prompt "silkworm" --device cuda

# Generate an augmented training set (see 2.5 for the SAM3-only recipe)
python utils/augment_mixed_10k.py --help
```

Useful flags of `augment_mixed_10k.py`: `--goal` (number of images), `--sam3-only` (skip Silkynet), `--same-class-paste` (one class per image), `--name-prefix`, `--output-dir`, `--workers`, `--seed`.

## 🛡️ 5. Integrity Rules

1. **Raw data is read-only:** never edit `yolo_bbox/`, `sam3_seg/` or `silkynet_seg/` by hand; regenerate derived sets instead.
2. **Never commit data:** `data/` and `runs/` are excluded via `.gitignore`.
3. **Strict filename matching:** `images/<stem>.jpg` ↔ `masks/<stem>.png` ↔ `labels/<stem>.txt` share the same stem.
4. **Report valid/test per domain:** SAM 3 single-larva images and Silkynet multi-larvae images behave very differently; do not average them.
