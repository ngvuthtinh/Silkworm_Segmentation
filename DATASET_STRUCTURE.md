## 🏷️ 2. Detailed Dataset Specifications

### 2.1. `data/Silkworm Diseases.v1i.yolo26` (YOLO Disease Dataset)
- **Primary Goal**: Disease classification and bounding box localization.
- **Classes**:
  - `0`: **Grasserie** (Viral NPV disease in silkworms)
  - `1`: **Healthy** (Normal healthy silkworm)
- **Annotation Format**: Standard YOLO format (`.txt` file matching image name):
  ```text
  <class_id> <x_center> <y_center> <width> <height>
  ```
  *(Coordinates normalized in `[0.0, 1.0]`)*

---

### 2.2. `data/Silkworm_SAM3_Segmented` (SAM 3 High-Precision Pseudo-Masks)
- **Primary Goal**: Providing dense pixel-level ground truth masks generated automatically via `utils/sam3_label_from_yolo.py` using **SAM 3 (Segment Anything Model 3)**.
- **Directory Structure (train / valid / test)**:
  - `masks/`: Single-channel PNG binary masks (`0` = background, `255` = silkworm body).
  - `boundaries/`: 2px boundary contour edge masks for boundary-guided loss computation.
  - `labels/`: Polygon segmentation format.
  - `visualizations/`: Overlay images to inspect mask quality.

---

### 2.3. `data/silkworm_mixed_dataset` (Primary Joint Multi-Task Dataset)
- **Primary Goal**: Training joint Multi-Task Segmentation & Classification models (e.g. `multitask_vmunet`).
- **Statistics (`dataset_summary.json`)**:
  - **Train**: 599 samples (99 multi-larvae legacy images + 500 SAM 3 single-larva images)
  - **Valid**: 110 samples (10 multi-larvae legacy images + 100 SAM 3 single-larva images)
  - **Test**: 169 samples (69 multi-larvae legacy images + 100 SAM 3 single-larva images)
- **Each split contains**:
  - `images/`: RGB source images (`.jpg` / `.png`).
  - `masks/`: Binary ground-truth masks (`.png`).
  - `labels/`: YOLO classification label files (`.txt`).

## 🛠️ 4. Data Processing Utilities (`utils/`)

### Generate Pseudo-Masks with SAM 3:
If new images with YOLO bounding box annotations are added, run:
```bash
python utils/sam3_label_from_yolo.py \
    --input-yaml "data/Silkworm Diseases.v1i.yolo26/data.yaml" \
    --output-dir "data/Silkworm_SAM3_Segmented" \
    --prompt "silkworm" \
    --device cuda
```

### Convert Bounding Boxes to Rectangle Masks:
```bash
python -m utils.yolo_bbox_to_masks \
    --input-root "data/Silkworm Diseases.v1i.yolo26" \
    --output-root "data/converted"
```

## 🛡️ 5. Dataset Integrity & Management Rules

1. **Original Raw Datasets are Read-Only**: Never edit or overwrite source image files inside `Silkworm Diseases.v1i.yolo26/` or `models/silkynet/data/`.
2. **Never Commit Large Datasets to Git**: Raw dataset directories (`data/`, `runs/`) are excluded via `.gitignore`.
3. **Strict Filename Matching**: Source images (`images/`) and target binary masks (`masks/`) must share identical file stems (e.g., `image_001.jpg` matches `image_001.png`).
